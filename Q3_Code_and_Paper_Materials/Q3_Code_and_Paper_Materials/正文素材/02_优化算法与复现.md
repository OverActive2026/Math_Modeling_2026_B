# 2 实际使用的优化方法

## 2.1 不要把所有算法都写成“全局优化已收敛”

现有工作是物理模型直接评价、六变量差分进化、定向候选检验、局部功率/时间精修和严格求解复核的组合。协同六变量联合搜索是核心；纯预热结果由已有能耗搜索档案及后续候选、过温时刻精修得到。不能把协同多起点DE的运行次数照搬成纯预热也完整执行过相同流程。

## 2.2 差分进化

协同将t_h除以96.6667 s归一化，与五个q共同组成[0,1]^6内变量。采用DE/rand/1/bin：
\[
v_i=\Pi_{[0,1]^6}\{x_{r_1}+F(x_{r_2}-x_{r_3})\},\quad F=0.65.
\]
二项交叉率CR=0.85，至少一个分量来自变异向量。代内固定父代，避免候选评价顺序改变变异基础。选择优先可行性；失败候选不能替代可行最低能耗档案。全局最低能耗记录严格单调不增；种群替换中的0.1 J容差不等于允许最终档案牺牲能耗。

第四轮实际执行：两个不同初始种群，每组8个个体、各2个完整变异代，随机种子7311和8429。16个初始记录复用，32个变异候选评价，可能命中缓存，不能说成32次全新物理积分。32个候选28个成功、4个物理失败，无一改善既有最低能耗。这一规模不足以证明收敛。

## 2.3 定向搜索与时间变量

- 检验均匀降功率、中间片降功率、端片降功率、稀疏供热、多片联合变化。
- 以能量预算E_b引导共同时间：t_h=E_b/(25Σq_k)，再完整模拟判断可行性。
- 在接近可行边界处缩小功率步长，精修纯预热首次过温时刻，删除成功后冗余的计划加热尾段。
- 对3个不同可行分配分别检查3777.902110 J和3768.402110 J预算，共6个撤热方案；均因电压下降到0.30 V失败。这只排除这些候选，不排除该预算下所有分配。
- 先前12次定向评价、8次预算评价等见原始CSV。各轮档案可能重叠和复用，不将历史报告计数简单相加冒充独立仿真次数。

## 2.4 已修复的算法问题

1. 最低能耗比较器曾允许0.1 J内以更短时间替换，引起最低能耗逐步上升；已改为严格能耗优先。
2. 边界截断形成相同候选；局部搜索跳过无变化方向。
3. 局部更优解不能进入DE种群；现允许代际导入，保持代内父本固定。
4. 固定种子覆盖整个小种群，使改变随机种子无效；现支持显式不同初始种群，并纳入断点指纹。
5. 数值求解异常单独标记并重试，不能将半截轨迹的低能耗算作成功。

注意：原评价器仍把孔隙占用0.98触发视作不可行；本包没有悄悄替换该历史实现。

## 2.5 可放入论文的伪代码

```text
输入：固定物理参数、五片功率边界、共同加热时间范围、启动约束
载入基准及已保存候选，初始化最低能耗可行档案
针对协同策略构造不同初始种群
重复有限代：
    固定本代父本，差分变异、二项交叉、边界投影
    对每个新候选调用完整瞬态模型
    停热后继续观察协同启动；检查成功、物理事件或数值异常
    依可行性和能耗更新种群；严格按能耗更新最佳档案
补充功率邻域、稀疏加热及共同停热预算检查
用原空间网格、更严格时间积分设置复核候选及全功率基准
输出成功记录的E_k、E_aux、t_s、最大冰体积分数及表4
```
