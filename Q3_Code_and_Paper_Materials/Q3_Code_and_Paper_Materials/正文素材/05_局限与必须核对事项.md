# 5 提交前必须核对的事实与局限

本文件不是把原结果作废，也不是认定其已经完全符合题目。其目的在于说明原结果对应什么实现、哪些结论有证据。

## A 参数与模型一致性（优先处理）

1. **活化能**：原代码Ea=8000 J/mol，题目备注给67000 J/mol；原校准代码固定8000而拟合其他参数，不能说8000已经作为自由参数校准得到。必须追溯问题1、2最终口径。不能直接改Ea后仍沿用本表，也不能宣称全部参数严格采用附件。
2. **板层计数**：原shared_stack总热容相当于6块2 mm板；题给阳/阴极板各2 mm，但共用板实体定义尚需核对。增加独立温度节点必须守恒原有物理体积，不能顺带变成10块并比较能耗。V2因此暂停，不进正文正式结果。
3. **孔隙占用0.98**：原程序纳入可行性判定，题给正式冰体积分数阈值为0.99，两者不相同。成功记录可被保存，但额外条件可能排除题目本来允许的低能耗候选，影响“最小能耗”结论。
4. **冰约束时间范围**：原配置iceScope='terminal'，正式要求应逐字核对原题。最终报告的两项全程输出最大值已低于0.99，但这不能消除搜索中终态/全程判据不同的风险。
5. **水质量守恒风险**：后续V2审查曾在继承的水模块上发现干节点仍有出流、被非负积分约束补偿的问题。该问题对原版两项记录的定量影响尚未在原条件下重算；不能将V2诊断百分比移植给原版，也不能称原版已通过完整水质量守恒验证。本包保留原代码，未混入V2修复后结果。

## B 热模型与数值解释

- 热源体积均匀折算，BP热容等效合并，未显式计算电热丝位置/热容及局部热点。
- 原热物性采用固定等效形式，没有逐项按水、冰、气体含量动态更新全部热物性；不应写“附件全部参数均完整实现”。
- 题目忽略界面热接触热阻，不能擅加热接触电阻；电接触电阻是另一个物理量。
- 时间积分更严格复核不代表空间网格收敛；当前网格[2,3,4,4,2]。
- 瞬时热网络残差接近机器精度只验证该状态下的热流连接，不证明长期水质量、全部能量闭合或模型准确性。
- 原参数审查报告指出附件初始液水/冰为0。不要仅因为认为“纯预热太理想”就在正式基准里擅加残余冰；如做敏感性必须另列条件。

## C 结论强度

可写：当前模型下已验证最佳可行记录；协同辅助能耗比纯预热低约9.81%；端片升温受端板吸热影响；近满功率区域包含当前最低记录。

不可写：已证明全局最优；所有功率分配均比较完毕；0.995588043具有九位物理有效精度；网格已收敛；协同同时具有最低冰量；启动后可长期稳定带载；模型参数完全题定；新模型已优于原版。

## D 与队友问题1、2统一的清单

统一符号和单片平均温度定义；确认gammaIce/kFreeze与Ea的来源；核对板层共享关系及总热容；核对冰与电压条件的作用时间范围；明确额外孔隙占用条件；报告原始网格和容差；明确能耗仅为辅助电加热；保留结果精度及“有限搜索”表述。上述事项若改变物理实现或可行域，须重新复算结果，不能只修改论文文字。
