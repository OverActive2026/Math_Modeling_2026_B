# 3 结果分析与可编辑正文

## 3.1 可直接改写的结果段落

在初始温度和环境温度均为−30 ℃、各片功率密度不超过1 W/cm²的条件下，采用原五片耦合瞬态模型进行有限次数的功率分配和共同加热时长搜索。纯预加热策略的最低能耗可行记录为五片均取1 W/cm²，加热并启动完成于33.5163 s，总辅助能耗4189.537 J，各片能耗均约837.907 J。恒定功率协同策略的对应分配为(1,1,1,1,0.995588043) W/cm²，启动时间30.2539 s，总辅助能耗3778.402 J，前四片各消耗756.348 J，第五片消耗753.011 J。上述结果通过原空间网格下更严格的时间积分复核，为当前模型与已执行搜索范围内的最佳可行结果。

相对于纯预热，协同策略减少辅助电热能411.135 J，降幅约9.813%，启动提前3.2624 s，缩短约9.734%。该比较仅涉及辅助电热丝能耗，不代表包括氢耗及其他辅机功率的系统总能耗降低相同比例。协同阶段同时发生电化学产热和产水，需要兼顾升温与结冰。

## 3.2 冰堵与端部差异

|指标|纯预热|恒功率协同|
|---|---:|---:|
|全程输出记录最大冰体积分数|0.011602795|0.119673228|
|两端片最大冰体积分数|0.011602795|0.119673228|
|中央片最大冰体积分数|0.005725399|0.033039592|
|记录中最小单片电压/V|1.225011090|0.630831914|
|累计电荷/C·cm⁻²|0|2.288248084|

这里的“中央片”指第3片；最大值由保存输出轨迹归纳，不是对连续时间每一瞬间求解析最大值。纯预热无电化学反应电流，但基础模型包含初始水合、水迁移与冻结，因此仍报告少量冰；不能写成“无电流所以绝不结冰”。纯预热电压是模型零电流状态下的计算量，不是带载性能验证。

协同方案虽然能耗较低、启动较快，其端片最大冰体积分数却较高。因此在本算例中，不能声称协同在能耗、速度和冰堵抑制三项上同时占优。纯预热的冰积累指标更低；协同需要解释反应产水与升温之间的竞争。

## 3.3 为什么接近满功率

协同完成时五片平均温度约为(0.0100,14.4777,19.2411,14.4667,0.0100) ℃，两侧端板约为(−18.8581,−18.8739) ℃。中间单片明显更暖，两端片构成过零瓶颈。在保持此状态与电流不变、瞬时撤去辅助热源的诊断中，第二片向第一片传热32.1363 W，第四片向第五片传热32.1119 W；两端片向端板分别传热52.0295 W、52.0729 W。

端板对环境散热仅约1.10 W/侧，其余大部分用于端板蓄热。端板尚低于0 ℃与单片满足启动条件并不矛盾。辅助加热停止后的两端片瞬时降温速率约为−1.519和−1.507 K/s，说明该状态下端部热储备有限；这不是额外规定必须继续加热，也不是启动后长期带载能力已验证的证据。

由于E_aux=25(Σq_k)t_h，降低功率只有在加热时间增加得足够少时才节能。中间片的热量会帮助端片升温，降低中间功率可能延迟端片过零。因此“中间温度高”不能直接推出“中间加热必然浪费”。该解释适用于已计算的模型状态和候选，不构成全局最优性证明。

## 3.4 微小功率分配优势的准确表述

同精度五片全满功率协同基准能耗为3780.461071 J，当前分配仅节约约2.058960 J，即约0.0545%。尚未检验空间离散误差是否小于此差值，故推荐写“最低记录位于接近满功率区域”，不写“精确最优功率为0.995588043”。左右微小不对称可能包含数值因素，不能直接解释为物理端部结构不对称。

## 3.5 推荐结论段

在所采用的降阶水热电模型及计算设置下，恒定功率协同启动相对于纯预加热减少了辅助电能并缩短启动时间，但具有更高的端片冰积累。端板热惯性及片间传热共同影响最冷端片升温，使已发现低能耗解集中在高功率区域。结果说明优化应同时处理功率分配与加热时长；现有有限搜索尚不能证明全局最优，微小功率调整的收益仍需进一步验证。
