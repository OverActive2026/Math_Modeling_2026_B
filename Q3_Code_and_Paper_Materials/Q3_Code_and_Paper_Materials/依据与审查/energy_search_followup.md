# 六变量能耗优化续审

## 已确认的问题

1. 原差分进化档案只有24次评价（12个初值和一代变异）。这只能说明探索开始，不能据此宣称收敛。
2. 当输入求解容差已经小于等于重试阈值时，旧重试仍采用完全相同的容差和最大步长。已用注入数值失败的回归测试复现并修复：第二次相对/绝对容差再收紧10倍、最大步长减半，空间网格与物理参数保持不变。
3. 前期主要在接近满功率的连续加热邻域进行精修，可能遗漏较低功率、较长时间和部分片零功率的方案。新定向搜索显式加入这些候选；它们是否节能必须以成功启动为前提。
4. 旧纯预热优化脚本在首次过温事件后固定追加0.01秒再停热。该数值缓冲会使每个满功率方案多计约1.25 J，并可能掩盖微小分配收益。首次试用1e-5秒裕量的两个候选复算后最低温度仍约0.00992 ℃，低于原模型0.01 ℃阈值，因此未接受。`q3_refine_preheat_timing` 改为根据实际温度短缺和末段温升速率提出补足时间，并由完整仿真重新判断；模型原有温度判据不变。旧入口亦在接近阈值但未过温时增加一次1毫秒缓冲的复算，避免直接接受或错误终止。

## 本轮方法与范围

入口为 `q3_continue_energy_search(N)`，每次评价保存完整物理轨迹、状态和累计最佳值，可断点继续。先复算数值未判定点，再检查联合降功率、共同提前停热、两类低功率长加热和纯预热中心降功率；随后沿五片独立功率方向围绕当前最佳可行点搜索。

五片共用一个加热持续时间。能耗指电热丝输入电能，不单独最小化瞬时功率，也不将散热量替代辅助能耗。没有新增启动时间上限或逐片关热控制。

成功方案与物理失败、数值未知分别存档。数值未知的部分积分能耗不能成为有效最低能耗。当前搜索仍无全局最优性证明；详细评价和结果以 `q3_targeted_history.csv`、`q3_final_energy_table.csv` 为准。

## 本轮已验证结果

- 协同：`[1,1,1,1,0.995588043208565] W/cm²`，共同计划加热时间30.253922673188秒，成功时刻30.2539126731895秒，实际能耗3778.40211026154 J。相对上一轮可行分配再降低0.686455 J，相对同精度全功率降低2.058960 J。
- 纯预热：五片满功率，共同加热33.5162966645716秒，能耗4189.53708307145 J。较旧结果减少1.181234 J，来源是缩减过温后的数值时间缓冲。
- 定向检查11项，其中新的最低协同候选来自原先数值未判定的第5片降功率方案。两片联合降功率及五个进一步逐片降功率方向均未超过它。
- 新最佳点提前0.01秒统一关热、中间片零功率且其余片长加热、全片半功率加热60秒这三个样本均物理失败，不能用其较低累计能耗作为有效最优值。
- `test_q3_energy_retry` 通过；最终两种方式均由完整模型复算成功，输出表各片能耗之和与总能耗一致。保留原空间网格，未进行细网格仿真。

这些结果证明本轮确实找到更低能耗的可行点，不证明六维域已经搜索充分，也不证明非均匀分配具有显著工程收益。
