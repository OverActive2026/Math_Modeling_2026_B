# 端部传热、模型范围与数值结论审查

本次审查针对当前文件夹中的基础模型与Q3调用链，不以“出现接近满功率的结果”作为最优性证据。

## 确认进入计算的物理项

`pemfc_stack5_simulate_q3.m` 按相邻单电池平均温差和串联热阻计算片间热通量，并以等大反向通量进入相邻单片边界。两端单电池与独立端板温度状态耦合；端板包括热容、与电池的导热以及对环境的对流。其结构与当前 `pemfc_stack5_simulate.m` 的对应热网络一致。

Q3单片状态方程调用现有 `water_ice_state_ice`、`thermal_temperature_state_ice`、`gas_transport_state_ice`。水冰相变、膜/催化层水合、气体传输、电压损失、电化学反应热和相变潜热均在该调用链中。优化程序使用这个模型进行候选评价。

## 新增的瞬时热量核对

在已保存的协同启动状态进行诊断，保持所有状态和题定电流，仅将辅助热源设为零。第二片向第一片传热32.1363 W，第四片向第五片传热32.1119 W；两端片分别向端板传热52.0295 W、52.0729 W。

此时端板对外散热分别只有1.0995 W、1.0980 W，其余约50.93 W、50.97 W进入端板蓄热。不能将端板吸热全部称为对环境的热损失。第一片电化学反应热为2.6420 W、相变热为−0.2546 W；撤热后净蓄热率为−17.5058 W。

整个电堆（含端板）的瞬时热平衡残差约−2.22×10⁻¹⁵ W，核对通过。这能验证该状态下传热项的守恒连接，不能验证网格收敛、材料参数真实性或全局最优性。数据见 `q3_heater_off_diagnostic.json`。

## 必须保留的结论限制

1. 现有模型用单片平均温度构造片间热网络；双极板热容折算进等效热容，没有独立双极板温度节点。辅助热源均匀折算到单片体积，保留每片输入功率积分，但不解析电热丝附近的空间热点。加密现有网格不能自动消除这些结构简化。
2. 现有结果使用[2,3,4,4,2]空间网格，没有完成空间网格收敛检查。收紧ODE容差与时间步长不能代替空间网格检查。
3. 选定分配相对全满功率的约2.059 J收益仅约0.054%。尚无证据表明这一收益大于空间离散误差，因此不能认定第五片0.995588043具有相应物理有效精度，也不能将其解释为已确认的节能优势。
4. 两个8个体种群、各两代搜索，以及局部撤热失败结果，不构成六维连续决策域的全局最优性证明。已保存记录中可行初值较多集中于高功率区域，存在搜索偏向的风险。
5. 辅助能耗取决于总功率和实际加热时长的乘积。当前模型中中间片向端片供热，降低中间功率可能延长加热时长；这解释了部分已计算候选能耗增加，但不能推出所有降功率方案都更差。

目前适当的表述是：**在当前降阶模型、原空间网格和已完成有限搜索下，最低能耗可行记录位于接近满功率区域。最优分配及微小能耗差异尚未得到空间离散收敛验证。**

若要排除网格误差，应先对满功率、现有候选和一个明显降低中间功率的候选做相同物理条件下的有限网格对照，判断排序与能耗差是否稳定，再决定是否重新优化。无需一开始就对整个优化过程使用细网格。
