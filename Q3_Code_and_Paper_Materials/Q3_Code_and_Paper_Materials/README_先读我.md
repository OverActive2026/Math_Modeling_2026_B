## 推荐阅读顺序

1. 正文素材/01_题意与数学模型.md：变量、能量计量、启动条件、热网络。
2. 正文素材/02_优化算法与复现.md：真正执行过的算法及规模，避免写成未运行的方法。
3. 正文素材/03_结果分析与可用正文.md：有数据依据的段落和比较。
4. 正文素材/04_图表说明与答辩问题.md：图注、写作结构及常见问题。
5. 正文素材/05_局限与必须核对事项.md：提交前必须阅读，尤其活化能、板层定义、额外孔隙占用条件。

“结果与图表”内包含原生可编辑表4 Word、PDF、完整精度CSV、MAT轨迹及SVG比较图；MATLAB导出工具可从保存记录导出逐时刻CSV，不重新积分。“依据与审查”是原审查记录，部分早期文字带有历史阶段性结论，以本包综合说明及最终CSV为准。“Code”保留当前原版全部m文件及导出脚本；使用时先切换到该目录，防止MATLAB调用到V2同名函数。

## 使用边界

- 不把第五片0.995588043解释为九位小数均具有物理意义；保留它是为了复现。
- 不把端板吸热全部写成环境散热，也不把冰体积分数写成孔隙冰饱和度。
- 不把纯预热时间再加上60秒电流加载时间。
- 不声称新模型优于旧模型，不采用V2中10块独立板的假设。
- 本包正文是可编辑的写作素材，作者应结合问题1、2最终模型和原题公式统一符号后使用。
