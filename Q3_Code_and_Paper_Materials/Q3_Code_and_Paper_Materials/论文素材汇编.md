# 第三题论文写作素材汇编

对应原模型保存结果；重要限制见第5章，不采用暂停的V2结果。

# 1 题意、变量和模型表达

## 1.1 问题定位

在问题2的五片单电池瞬态水热电模型上加入辅助加热项，分别优化纯预加热和恒定功率协同启动。目标是满足启动条件时尽可能减少辅助电热丝的总能耗，并报告总启动时间、各片能量分配和端片结冰指标。初始温度、环境温度均为−30 ℃。

纯预热：加热阶段电流为零，以五片单电池均超过0 ℃作为本问预热启动完成。论文表中的启动时间不再追加带载爬坡时间。恒功率协同：从t=0同时加热和加载电流；加热功率恒定并不表示电堆输出功率恒定。

## 1.2 决策变量与功率

\[
\boldsymbol x=(q_1,q_2,q_3,q_4,q_5,t_h),\qquad 0\le q_k\le1\ {\rm W/cm^2},\quad t_h\ge0.
\]

五片使用同一个计划加热时长，允许某片q_k=0；本问没有采用分片提前停热、多阶段功率或反馈控制。搜索保留五片独立功率，没有强制左右对称。相同面积A=25 cm²时：

\[
p_k(t)=Aq_k\mathbf1_{0\le t<t_h}=25q_k\mathbf1_{0\le t<t_h}\ {\rm W}.
\]

对应到原一维单片热方程的体积热源为S_aux,k=10^4 q_k/L_MEA，单位W/m³，加热关闭后为0。该表达保留输入功率积分，但属于均匀折算热源，未解析双极板或电热丝局部温度。

协同加载：
\[
j(t)=\begin{cases}0.005t,&0\le t\le60\ {\rm s},\\0.3,&t>60\ {\rm s}.\end{cases}
\]
单位A/cm²。纯预热本问计时范围内j(t)=0。

## 1.3 能耗和优化问题

设t_s为判定成功的时刻，计量到成功或停热先发生者：
\[
t_{h,\mathrm{used}}=\min(t_h,t_s),\quad E_k=25q_k t_{h,\mathrm{used}},\quad E_{\mathrm{aux}}=\sum_{k=1}^{5}E_k.
\]

以上只用于成功候选；失败轨迹累计了更少电能，也不能进入最优答案。若协同先停热再依靠反应热升温，仍继续仿真直到成功或失败，不能把停热时刻等同于启动时刻。最佳记录恰好在完成启动前保持加热，因此本表实际加热时间和启动时间相等。

\[
\min_{\boldsymbol x\in\mathcal F} E_{\mathrm{aux}}(\boldsymbol x).
\]

主目标是辅助能耗；全局档案仅在能耗相等时比较启动时间。没有另设“25秒以内”或人为能耗均匀约束。时间作为比较指标，并受题给成功条件和累积电荷上限约束。没有把氢耗、电堆输出电能或其他辅机电耗计入E_aux。

## 1.4 启动条件与数值实现分开写

题给温度条件为min_k Tbar_k(t_s)>0 ℃，单片电压不低于0.30 V，冰体积分数低于0.99；同时满足问题2电流及累积电荷约束。冰条件的时间范围应对照原题公式，不以本包文字替代原题。

原代码采用0.01 K过零裕量，故记录对应最冷单片约0.01 ℃。当前配置iceScope='terminal'检查终态冰条件，同时导出全程输出记录中的最大冰体积分数。本次两项成功结果的全程最大值都远小于0.99。原代码另外施加maximumPoreOccupancy=0.98，属于额外模型限制，不能称为题目正式约束；这会影响可行域和最优性结论。

协同电荷：Q(t)=0.0025t²（t≤60），Q(t)=9+0.3(t−60)（t>60），单位C/cm²。Q≤20对应最长观察时刻约96.6667 s。这由题定电荷上限推出，不是任意增加的启动时限。

## 1.5 原模型的热网络

各单片保留气体、水/冰、水合和温度状态；电压由可逆电势及活化、欧姆、浓差损失组成。解释层面可写：
\[
V_k=E_{\mathrm{rev},k}-\eta_{\mathrm{act},k}-\eta_{\mathrm{ohm},k}-\eta_{\mathrm{con},k},
\qquad Q_{\mathrm{rxn},k}=I(E_{\mathrm{th}}-V_k).
\]
细节沿用问题1、2代码，不能另引一套未经运行的经验式。冻结参数kFreeze=0.4，冰影响参数gammaIce=3.5，具体单位和函数形式以water_ice_state_ice等源程序为准。

单片能量平衡的积分示意式：
\[
C_k\dot{\bar T}_k=Q_{\mathrm{rxn},k}+Q_{\mathrm{phase},k}+p_k+
\sum_{\ell\in\mathcal N_k}G_{k\ell}(\bar T_\ell-\bar T_k)-Q_{k\to e}.
\]
这是解释热流的示意式，实际代码对一维温度场离散积分，并非仅有五个温度未知数。片间G=A/R''，R''由MEA和板材导热热阻构成；每条界面通量对相邻单片等大反向。端板独立满足：
\[
C_e\dot T_e=G_{ke}(\bar T_k-T_e)-hA(T_e-T_{\mathrm{amb}}).
\]
因此端板蓄热与环境散热分开计量。

当前代码shared_stack将板热质量分摊到单片：[0.75,0.5,0.5,0.5,0.75]乘以“两块2 mm板”的基础热容，合计相当于6块2 mm板；没有独立BP温度节点。这是现有实现口径，尚不能写成题目已确认6块。题目明确阳极、阴极板厚均2 mm、端板10 mm，实体共用板与两侧板厚定义仍需统一。切勿采用已停用V2的10块计数。

## 1.6 数值方法

原网格按五层分配[2,3,4,4,2]个控制体，采用刚性ODE求解及事件检测。最终复核保持空间网格不变，RelTol=1e−6、AbsTol=1e−10、MaxStep=0.0125 s。该过程是更严格的时间积分复核，不是空间网格收敛验证。

# 2 实际使用的优化方法

## 2.1 不要把所有算法都写成“全局优化已收敛”

现有工作是物理模型直接评价、六变量差分进化、定向候选检验、局部功率/时间精修和严格求解复核的组合。协同六变量联合搜索是核心；纯预热结果由已有能耗搜索档案及后续候选、过温时刻精修得到。不能把协同多起点DE的运行次数照搬成纯预热也完整执行过相同流程。

## 2.2 差分进化

协同将t_h除以96.6667 s归一化，与五个q共同组成[0,1]^6内变量。采用DE/rand/1/bin：
\[
v_i=\Pi_{[0,1]^6}\{x_{r_1}+F(x_{r_2}-x_{r_3})\},\quad F=0.65.
\]
二项交叉率CR=0.85，至少一个分量来自变异向量。代内固定父代，避免候选评价顺序改变变异基础。选择优先可行性；失败候选不能替代可行最低能耗档案。全局最低能耗记录严格单调不增；种群替换中的0.1 J容差不等于允许最终档案牺牲能耗。

第四轮实际执行：两个不同初始种群，每组8个个体、各2个完整变异代，随机种子7311和8429。16个初始记录复用，32个变异候选评价，可能命中缓存，不能说成32次全新物理积分。32个候选28个成功、4个物理失败，无一改善既有最低能耗。这一规模不足以证明收敛。

## 2.3 定向搜索与时间变量

- 检验均匀降功率、中间片降功率、端片降功率、稀疏供热、多片联合变化。
- 以能量预算E_b引导共同时间：t_h=E_b/(25Σq_k)，再完整模拟判断可行性。
- 在接近可行边界处缩小功率步长，精修纯预热首次过温时刻，删除成功后冗余的计划加热尾段。
- 对3个不同可行分配分别检查3777.902110 J和3768.402110 J预算，共6个撤热方案；均因电压下降到0.30 V失败。这只排除这些候选，不排除该预算下所有分配。
- 先前12次定向评价、8次预算评价等见原始CSV。各轮档案可能重叠和复用，不将历史报告计数简单相加冒充独立仿真次数。

## 2.4 已修复的算法问题

1. 最低能耗比较器曾允许0.1 J内以更短时间替换，引起最低能耗逐步上升；已改为严格能耗优先。
2. 边界截断形成相同候选；局部搜索跳过无变化方向。
3. 局部更优解不能进入DE种群；现允许代际导入，保持代内父本固定。
4. 固定种子覆盖整个小种群，使改变随机种子无效；现支持显式不同初始种群，并纳入断点指纹。
5. 数值求解异常单独标记并重试，不能将半截轨迹的低能耗算作成功。

注意：原评价器仍把孔隙占用0.98触发视作不可行；本包没有悄悄替换该历史实现。

# 3 结果分析与可编辑正文

## 3.1 可直接改写的结果段落

在初始温度和环境温度均为−30 ℃、各片功率密度不超过1 W/cm²的条件下，采用原五片耦合瞬态模型进行有限次数的功率分配和共同加热时长搜索。纯预加热策略的最低能耗可行记录为五片均取1 W/cm²，加热并启动完成于33.5163 s，总辅助能耗4189.537 J，各片能耗均约837.907 J。恒定功率协同策略的对应分配为(1,1,1,1,0.995588043) W/cm²，启动时间30.2539 s，总辅助能耗3778.402 J，前四片各消耗756.348 J，第五片消耗753.011 J。上述结果通过原空间网格下更严格的时间积分复核，为当前模型与已执行搜索范围内的最佳可行结果。

相对于纯预热，协同策略减少辅助电热能411.135 J，降幅约9.813%，启动提前3.2624 s，缩短约9.734%。该比较仅涉及辅助电热丝能耗，不代表包括氢耗及其他辅机功率的系统总能耗降低相同比例。协同阶段同时发生电化学产热和产水，需要兼顾升温与结冰。

## 3.2 冰堵与端部差异

|指标|纯预热|恒功率协同|
|---|---:|---:|
|全程输出记录最大冰体积分数|0.011602795|0.119673228|
|两端片最大冰体积分数|0.011602795|0.119673228|
|中央片最大冰体积分数|0.005725399|0.033039592|
|记录中最小单片电压/V|1.225011090|0.630831914|
|累计电荷/C·cm⁻²|0|2.288248084|

这里的“中央片”指第3片；最大值由保存输出轨迹归纳，不是对连续时间每一瞬间求解析最大值。纯预热无电化学反应电流，但基础模型包含初始水合、水迁移与冻结，因此仍报告少量冰；不能写成“无电流所以绝不结冰”。纯预热电压是模型零电流状态下的计算量，不是带载性能验证。

协同方案虽然能耗较低、启动较快，其端片最大冰体积分数却较高。因此在本算例中，不能声称协同在能耗、速度和冰堵抑制三项上同时占优。纯预热的冰积累指标更低；协同需要解释反应产水与升温之间的竞争。

## 3.3 为什么接近满功率

协同完成时五片平均温度约为(0.0100,14.4777,19.2411,14.4667,0.0100) ℃，两侧端板约为(−18.8581,−18.8739) ℃。中间单片明显更暖，两端片构成过零瓶颈。在保持此状态与电流不变、瞬时撤去辅助热源的诊断中，第二片向第一片传热32.1363 W，第四片向第五片传热32.1119 W；两端片向端板分别传热52.0295 W、52.0729 W。

端板对环境散热仅约1.10 W/侧，其余大部分用于端板蓄热。端板尚低于0 ℃与单片满足启动条件并不矛盾。辅助加热停止后的两端片瞬时降温速率约为−1.519和−1.507 K/s，说明该状态下端部热储备有限；这不是额外规定必须继续加热，也不是启动后长期带载能力已验证的证据。

由于E_aux=25(Σq_k)t_h，降低功率只有在加热时间增加得足够少时才节能。中间片的热量会帮助端片升温，降低中间功率可能延迟端片过零。因此“中间温度高”不能直接推出“中间加热必然浪费”。该解释适用于已计算的模型状态和候选，不构成全局最优性证明。

## 3.4 微小功率分配优势的准确表述

同精度五片全满功率协同基准能耗为3780.461071 J，当前分配仅节约约2.058960 J，即约0.0545%。尚未检验空间离散误差是否小于此差值，故推荐写“最低记录位于接近满功率区域”，不写“精确最优功率为0.995588043”。左右微小不对称可能包含数值因素，不能直接解释为物理端部结构不对称。

## 3.5 推荐结论段

在所采用的降阶水热电模型及计算设置下，恒定功率协同启动相对于纯预加热减少了辅助电能并缩短启动时间，但具有更高的端片冰积累。端板热惯性及片间传热共同影响最冷端片升温，使已发现低能耗解集中在高功率区域。结果说明优化应同时处理功率分配与加热时长；现有有限搜索尚不能证明全局最优，微小功率调整的收益仍需进一步验证。

**可否不同片不同时间关热？** 当前Q3采用共同时间，只优化五个恒定功率和一个时长。分片动态控制是不同控制问题，不能混入本表。

**启动能否达到25 s以内？** 当前最佳记录均高于25 s；已计算结果不能支持“可以”，也没有严格证明任何合法方案均不可能。

**为什么不是对称功率？** 搜索没有强制对称，第五片小幅下降产生数值层面的最低记录。微小不对称尚无稳健物理解释，不能宣称必要。

**启动成功是否代表端板也必须过零？** 否，当前判据作用于五片单电池平均温度；端板保留热惯性状态。不能自行把端板过零加成新约束。

**引用文献怎么处理？** 题目[5][6]应沿用原题完整文献条目，不凭本包补造编号。代码审查中列出的双极板/端板文献属于背景候选，不是当前参数已由文献验证的证据。当前正文主要依据原题、附件、代码和计算记录，不需要为每一个计算结果添加外部引用。

# 5 提交前必须核对的事实与局限

本文件不是把原结果作废，也不是认定其已经完全符合题目。其目的在于说明原结果对应什么实现、哪些结论有证据。

## A 参数与模型一致性（优先处理）

1. **活化能**：原代码Ea=8000 J/mol，题目备注给67000 J/mol；原校准代码固定8000而拟合其他参数，不能说8000已经作为自由参数校准得到。必须追溯问题1、2最终口径。不能直接改Ea后仍沿用本表，也不能宣称全部参数严格采用附件。
2. **板层计数**：原shared_stack总热容相当于6块2 mm板；题给阳/阴极板各2 mm，但共用板实体定义尚需核对。增加独立温度节点必须守恒原有物理体积，不能顺带变成10块并比较能耗。V2因此暂停，不进正文正式结果。
3. **孔隙占用0.98**：原程序纳入可行性判定，题给正式冰体积分数阈值为0.99，两者不相同。成功记录可被保存，但额外条件可能排除题目本来允许的低能耗候选，影响“最小能耗”结论。
4. **冰约束时间范围**：原配置iceScope='terminal'，正式要求应逐字核对原题。最终报告的两项全程输出最大值已低于0.99，但这不能消除搜索中终态/全程判据不同的风险。
5. **水质量守恒风险**：后续V2审查曾在继承的水模块上发现干节点仍有出流、被非负积分约束补偿的问题。该问题对原版两项记录的定量影响尚未在原条件下重算；不能将V2诊断百分比移植给原版，也不能称原版已通过完整水质量守恒验证。本包保留原代码，未混入V2修复后结果。

## B 热模型与数值解释

- 热源体积均匀折算，BP热容等效合并，未显式计算电热丝位置/热容及局部热点。
- 原热物性采用固定等效形式，没有逐项按水、冰、气体含量动态更新全部热物性；不应写“附件全部参数均完整实现”。
- 题目忽略界面热接触热阻，不能擅加热接触电阻；电接触电阻是另一个物理量。
- 时间积分更严格复核不代表空间网格收敛；当前网格[2,3,4,4,2]。
- 瞬时热网络残差接近机器精度只验证该状态下的热流连接，不证明长期水质量、全部能量闭合或模型准确性。
- 原参数审查报告指出附件初始液水/冰为0。不要仅因为认为“纯预热太理想”就在正式基准里擅加残余冰；如做敏感性必须另列条件。

## C 结论强度

可写：当前模型下已验证最佳可行记录；协同辅助能耗比纯预热低约9.81%；端片升温受端板吸热影响；近满功率区域包含当前最低记录。

## 数据文件读法

最终CSV的thRequestedS是计划停热时刻，thUsedS是实际计入能耗的加热时长；两者在协同最佳记录相差约1e−5 s，为事件附近的数值时间余量。正文表4使用实际加热时长。

trajectory.csv中每行是已保存的输出时刻，不是ODE内部所有自适应步；T1_C…T5_C为单片平均温度，ice1…ice5为各片空间最大冰体积分数，E1_J…E5_J为累计辅助能量。温度过零判断不能用全部材料节点温度替换单片平均温度。

两种策略的输出采样点数不同，不能将行号直接当作共同时间比较。需要同一时刻比较时应在有效时间范围内插值，不外推到启动终止之后。
