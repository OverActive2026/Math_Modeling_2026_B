# 问题3：外部电热丝辅助冷启动模型

本目录由 `Code_Q2_PhaseFix` 完整复制而来，保留问题2相变修正、五片热耦合、
独立端板节点和全部约束。问题3新增文件不会修改原 `Code_Q2_PhaseFix`。

## 1. 已加入的模型

题目给出每片电热丝恒定面功率密度

```text
0 <= q_k <= 1 W/cm^2,  k=1,...,5
```

现有一维状态只显式离散MEA五层，双极板热容已均匀折算进每片的等效体积热容，
没有独立双极板温度节点。为保持这一降阶口径，电热丝面功率先换算为
`q''_k=10^4 q_k [W/m^2]`，再定义均匀等效体积热源

```text
q_aux,k(x,t) = q''_k(t)/L_MEA
```

因此严格满足

```text
integral_0^L q_aux,k dx = q''_k
```

源项直接进入原能量方程：

```text
rhoCp_eff*dT/dt = div(k_eff*grad(T)) + q_gen + q_phase + q_aux
```

这里的“均匀”不是说真实电热丝位于MEA内，而是把双极板内热源投影到当前已经
均匀化了双极板热容的单片温度状态。若后续需要研究电热丝与MEA之间的瞬态温差，
应再增加显式双极板/电热丝温度节点。

## 2. 两种题设模式

- `preheat`：纯预加热，`j(t)=0`；五片平均温度同时达到0 ℃即完成预热，随后可加载电流。
  若电热丝先于该时刻关闭，即使之后因片间热再分配达到0 ℃，也判为不满足纯预热定义。
- `coheat`：从 `t=0` 同步加载电流和辅助热；电流固定为
  `j(t)=min(0.005t,0.3) A/cm^2`。

两种模式的电热丝都在 `0<=t<t_h` 内保持给定恒功率，之后关闭。模型仍检查问题2
的20 C/cm²电荷、0.5 A/cm²电流、0.30 V最低电压、冰体积分数和孔隙占用约束。

## 3. 能耗

每片能耗和总能耗按题目式(11)解析计算：

```text
E_k = A*q_k*min(t_h,t_stop)
E_aux = sum(E_k)
```

代码使用 `A=25 cm^2`，所以输入 `q_k [W/cm^2]` 后直接得到瓦特和焦耳。解析积分
不依赖ODE输出步长，也不会因加热关断端点的离散采样产生误差。

## 4. 主要文件

- `pemfc_stack5_simulate_q3.m`：问题3五片电堆核心，接入热源并输出能耗。
- `q3_auxiliary_heating.m`：五片恒功率及定时关断模型。
- `run_q3_model.m`：纯预加热与恒功率协同启动的入口脚本；其中参数只是候选值，尚未优化。
- `test_q3_auxiliary_heating.m`：功率开关、面/体热源守恒、能耗和零热源退化检查。
- `pemfc_stack5_simulate.m`：保留的问题2核心，用于零热源对照。

## 5. 调用示例

```matlab
opt = struct('initialTemperatureC',-30, ...
             'ambientTemperatureC',-30, ...
             'plot',true,'verbose',true);

[result,model] = pemfc_stack5_simulate_q3( ...
    'coheat',ones(1,5),80,opt);
```

关键输出包括：

## 9. 第二问的六维优化入口

`q3_optimization_config.m` 固定本轮试验参数：−30 ℃、`gammaIce=3.5`、
`kFreeze=0.4 s^-1`。六维决策是五片相互独立的恒功率密度和停热时间。
`q3_evaluate_candidate.m` 调用同一物理模型；纯预热在停热时判断题面过温，
协同启动使用题给的 60 s 电流斜坡。纯预热只计算预热阶段，
不附加题目没有规定的后续电流或额外观察时长。

```matlab
cfg = q3_optimization_config('smoke');
cfg.maxEvaluations = 12; % 每种模式的真实物理仿真次数上限
pre = q3_run_optimization('preheat',cfg);
co  = q3_run_optimization('coheat',cfg);
preAudit = q3_validate_best(pre); % 同一粗网格，按题面条件复算
coAudit  = q3_validate_best(co);
```

纯预热使用多起点坐标模式搜索，协同启动使用可行性优先的差分进化。
`cfg.guidance=true` 可开启五次单片功率扰动形成的等总功率转移提议；
探针和提议的物理仿真均计入评价预算。运行记录保存在 `results/`。
`q3_run_ablation(cfg,[20260925 20260926 20260927])` 可按相同预算运行
两种模式的基础/引导对照；本轮只验证了其接口，未执行耗时的正式消融。
`q3_optimization_config('full')` 使用相同粗网格、600 s 搜索范围和较大预算；
它不会自动运行。当前按用户要求不进行完整细网格复核。
搜索结果仅是有限预算、指定网格下找到的最低能耗可行候选，
不能声称已证明全局最优或重新校准了冰参数。

## 10. 本轮粗网格试运行结果

使用 `[2 3 4 4 2]`、−30 ℃、`gammaIce=3.5`、`kFreeze=0.4 s^-1`，
分别进行了纯预热12次、协同启动10次真实物理评价。结果及完整轨迹存放在
`results/`；`summary_question.csv` 是到题面首次达标时的指标。

题目规定的 `0.005 A/(cm²·s)` 升载至 `0.3 A/cm²` 明确写在
“除纯预加热启动外”之后，因此不属于纯预热的题面指定加载曲线。
因此纯预热仿真在停热时结束；问题2的最优加载曲线在本文件夹中
尚未确定。题面表4的纯预热“启动结果”按五片在预热结束时首次
同时满足问题2条件报告。

| 模式 | q（W/cm²） | 请求停热时间 | 实际加热时间 | 辅助能耗 | 题面首次达标 |
| --- | --- | ---: | ---: | ---: | ---: |
| 纯预热 | `[1 1 0.9 1 1]` | 35 s | 35 s | 4287.5 J | 35 s |
| 协同启动 | `[1 1 1 1 1]` | 60 s | 30.244 s | 3780.5 J | 30.244 s |

两组候选在各自当前模型的终止条件下复算达标。纯预热期间电流和
累计电荷均为零；协同启动达标时累计电荷约2.287 C/cm²。
按照本题采用的纯预热判定，五片温度均超过 0 ℃的时刻就是纯预热
策略的启动时间，因此表中的 35 s 是该策略的启动时间。纯预热
阶段电流为零；停热后的加载过程不计入这一时间。
协同模式的30 s停热边界候选消耗3750 J，但后来低压失败，
不能作为可行能耗。表中协同候选请求持续60 s，仿真在30.244 s
首次达标时停止，实际加热时间和能耗按这一时刻计算。
本轮评价预算有限，表内是已找到的可行记录，不是正式全局最优结果。

## 11. 启动时间优先试算

若目标改为缩短启动时间，可运行 `q3_optimize_startup_time`。该脚本不修改
物理模型，以每片功率上限 `1 W/cm²` 找首次达标事件，再把停热时间设在
事件附近并复算。运行 `q3_search_time_neighborhood` 可逐片检验功率降低，
运行 `q3_time_numerical_check` 可在同一网格用更紧容差复核。
结果见 `results/time_priority_candidates.csv` 和
`results/time_priority_report.md`。当前得到纯预热启动时间约 33.526 s、
协同启动时间约 30.244 s；这是有限候选的时间优先结果，
尚无全局最短时间证明。纯预热从零时刻加热至五片均超过 0 ℃，
该时刻即为本题采用的纯预热启动时刻。

## 13. 最小辅助能耗继续搜索

`q3_refine_min_energy('preheat',N)` 和
`q3_refine_min_energy('coheat',N)` 在不改变物理模型的条件下继续搜索。
它们首先在对称功率分配上搜索，再逐片检查独立功率，按每次物理
评价保存 `results/q3_min_energy_*_history.csv` 与 MAT 档案。纯预热
利用首次五片过温事件确定该功率分配的最短可行加热时长，并在接受
新最优候选前独立复算；协同启动使用题定电流曲线。

`q3_refine_coheat_duration` 单独检验提前停热，
`q3_retry_energy_failures('coheat')` 对数值失败的候选在同一网格
收紧容差重算。`q3_finalize_min_energy` 在同一粗网格上以更紧容差
复核两种方式的当前最低能耗可行候选，并输出
`results/q3_final_energy_table.csv`。表内是有限搜索找到并复核的
最低能耗候选，不等于六维连续决策域的全局最优性证明。

## 14. 六变量联合能耗搜索（当前入口）

运行 `run_q3_energy_optimization(24)` 可在保存的种群上追加24次
候选评估，然后复算两种方式的最佳记录并生成
`results/q3_final_energy_table.csv`、`results/q3_energy_results_report.md`
和 `results/q3_joint_de_history.csv`。24是追加评估数，不是全局最优
保证；`run_q3_energy_optimization(0)` 只对当前档案复算和导出。

协同搜索采用 `q3_joint_de_energy` 中的六变量差分进化，五片功率与
停热时刻独立变化，上一代父本固定，支持并行和断点恢复。
当前入口默认顺序计算，以避免多个 MATLAB 工作进程耗尽内存。
物理评价统一由 `q3_evaluate_energy6` 完成，关热后继续观察到
成功、物理失败或20 C/cm²电荷上限。固定电流下该上限对应约
96.6667秒，不能将加热时长用作整个启动过程的观察终点。

`q3_refine_min_energy` 的旧协同邻域记录主要覆盖连续加热方案，
不能代替当前六变量联合结果。`results/energy_search_audit.md`
记录了这个差别及加热开关分段积分的修正。纯预热仍按五片均超过
0 ℃的时刻报告启动时间。

`q3_thermal_allocation_screen` 只使用基础模型热网络生成纯预热
功率建议，其简化结果不进入题目结果表；最终表只接受完整含冰
物理模型复算成功的候选。

局部精修使用 `q3_small_allocation_probe` 测量微小降功率对端片温差
和总能耗的影响，`q3_refine_end_margin` 根据端片温差余量提出候选，
每个候选仍由完整物理模型评价。`q3_finalize_joint_results` 在相同
更紧容差下顺序复核选定分配与满功率基准，保存各次复核 MAT 文件。
当前协同可行分配为 `[1,1,1,0.990975820219714,1] W/cm²`，能耗
3779.089 J、启动30.287372 s；相对同精度满功率仅降低1.373 J，
不能据此宣称显著节能或全局最优。

## 15. 搜索遗漏与数值重试续审

`q3_continue_energy_search(N)` 追加定向搜索并逐次保存。最初六项检查
数值未判定点、两片联合降功率、统一提前停热、两类低功率长加热和
纯预热中心降功率；之后围绕当前最佳点轮流调整五片独立功率。
`q3_refine_preheat_timing` 从保存的轨迹中提取首次过温事件，缩减旧
脚本额外的0.01秒时间缓冲，并重新验证相应共同加热时长。
完成后运行 `q3_finalize_joint_results` 更新表格。历史段落中的数值
是各轮记录，最新结果以 `results/q3_final_energy_table.csv` 为准。

失败重试现在保证改变求解设置，回归测试为 `test_q3_energy_retry`。
数值失败仍归为未判定，不能以部分积分能耗参加可行方案排名。
续审说明见 `results/energy_search_followup.md`。

## 17. 两组初始种群与共同撤热边界

`q3_multistart_energy(2)` 使用两组不同的8个体初始种群，各完成两代
六变量差分进化。初始记录来自当前模型版本的已保存完整仿真，
分别侧重可行功率分配的差异和接近可行域的失败点；新变异点仍经
完整模型评价。自定义初始种群不再被原来的固定种子覆盖。
该入口使用两个工作进程，可断点继续；32次变异候选评价中允许
命中已有缓存，不能将计数直接解释为32次全新的物理积分。

`q3_multistart_cutoff` 从本轮记录中选取三个不同的可行功率分配，
检查更低总能量预算对应的共同停热时刻。它保留关热后的电流加载
和完整观察区间。`q3_finalize_joint_results(true)` 接纳这些记录并
复核；只有物理参数、代码、输入及求解选项均未改变的已完成复核
才可复用。随后重新运行第16节的Word/PDF导出命令。

`q3_heater_off_diagnostic` 在最终协同方案的启动状态计算全关热的
瞬时温度变化率，辅助解释端部热损失；该局部诊断不替代关热后
完整仿真，也不构成全局最优性证明。上述优化均沿用原空间网格。
