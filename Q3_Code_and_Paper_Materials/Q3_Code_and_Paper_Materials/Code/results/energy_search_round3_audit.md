# 六变量能耗优化第三轮复审

## 已复现和修正的算法问题

1. **最低能耗记录可能逐次升高。** 旧比较器允许能耗相差0.1 J时选择更快的候选。回归测试给出能耗100、100.09、100.18等、时间逐次缩短的可行记录，旧代码最终将100.45误记为最佳。现在全局档案严格保留最低能耗，仅能耗相等时比较时间；0.1 J容差仅保留为差分进化种群替换规则。`test_q3_energy_incumbent` 已通过。
2. **边界投影产生重复候选。** 局部搜索向已满功率的片继续增加功率，会被截回原点。现在区分提议序号和实际评价数，跳过没有变化的方向，避免耗费评价预算。
3. **较优的局部方案未进入差分进化种群。** 现在支持在完整代之间导入独立复核过的较优候选，替换一个失败或较差成员，记录导入时刻和槽位，保持代内父本冻结。`run_q3_energy_optimization` 自动读取最终档案提供候选；物理参数必须一致。

## 新补充的搜索

`q3_energy_budget_search` 对此前没有覆盖的0.6、0.7、0.9均匀功率，以及两端0.85、中间满功率的分配，令共同加热时间等于目标能量预算除以总加热功率，实际检查能耗比现有最低值低5 J的方案是否可行。随后缩小第5片功率步长，检查旧邻域步长之间的区域。

这是一组受能量预算引导的物理候选检验，并非已完成对整个六维域的可行性证明。低预算方案失败，只能排除对应功率与时间组合，不能排除这一预算下所有其他分配。

## 表4交付

`export_q3_table4.ps1` 从最终复核表生成与题目一致的八列表，输出中文 CSV、Markdown 和可浏览器查看或复制到 Word 的 HTML。表中保留共同加热时间、五片能耗、总启动时间、最大冰体积分数与成功状态。最终结论以复核后的文件为准。

`export_q3_table4_word.ps1` 生成原生可编辑Word表格和单页PDF。Windows原生PDF渲染用于检查实际页面，确认八列数据、边框和字体没有溢出。

## 本轮结果

本轮新增13项物理候选检查：8项预算及小步长检查、4项差分进化联合候选、1项去除重复边界后的局部候选。没有找到优于现有记录的可行方案。0.4功率方案在计划停热前即物理失败，3343.701 J只是失败前累计能耗。

当前纯预热为4189.537083 J、33.516297秒；协同为3778.402110 J、30.253913秒。二者均沿用原模型、原网格、gammaIce=3.5和kFreeze=0.4，五片共用加热时间。

回归测试 `test_q3_energy_incumbent` 和 `test_q3_joint_de_energy` 通过。实际局部续算跳过4个无变化的边界提议，记录的历史长度与真实候选评价数一致；代际较优候选导入已实际执行。修正算法错误并补充有限搜索，不等于证明全局最优。
