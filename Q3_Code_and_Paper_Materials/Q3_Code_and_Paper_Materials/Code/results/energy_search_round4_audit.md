# 第四轮能耗优化审查

本轮保留原物理模型、原空间网格、gammaIce=3.5、kFreeze=0.4、−30 ℃初温与环境、每片1 W/cm²功率上限以及统一加热持续时间。纯预热仍以五片过零为启动完成，协同启动仍采用题定电流斜坡。

## 已修正的搜索问题

原差分进化在初始化时先生成随机种群，再用固定种子覆盖前12个个体。当种群大小为12时，单独改变随机种子不会改变初始种群。本轮增加显式初始种群与已保存物理记录接口；不同初始种群及对应记录写入断点指纹，避免恢复时混用。

`test_q3_multistart_initialization` 先复现自定义种群被覆盖的问题，再验证自定义种群得以保留、保存种子无需重复积分、后续变异候选仍调用评价器。差分进化断点恢复和最低能耗记录回归测试同时通过。测试中的模拟能耗不属于物理仿真结果。

## 联合搜索的实际结果

使用当前模型版本下24个已保存物理记录，其中13个可行。第一组初值侧重不同可行分配，第二组加入低功率、稀疏功率和接近可行边界的失败分配。每组8个个体，随机种子分别为7311、8429，各运行2个完整变异代。

共16个复用初始记录和32个变异候选评价；后者可能命中缓存，不能等同于32次全新积分。32个变异候选中28个成功、4个物理失败，均未改善已有最低能耗。新变异候选中最低的成功能耗为3778.697944 J，功率分配为[1,1,1,0.998,0.996888043] W/cm²，启动时间30.260522 s。

这修正了初始种群缺乏差异的问题，但两个小种群、两代搜索仍不足以证明全局最优或算法收敛。

## 共同停热边界检查

`q3_multistart_cutoff` 从上述完整物理记录中选择三个不同的可行功率分配，对每个分配分别将辅助能量预算设为当前最低值减0.5 J、减10 J，并计算共同加热时长。关热后继续积分，保留电压、温度、冰、电荷和模型既有孔隙占用约束。

逐项结果保存在 `q3_multistart_cutoff_history.csv`，完整轨迹保存在 `q3_multistart_stop_*.mat`。结果表只接受成功候选；失败轨迹的部分或全部耗电量不能作为优化答案。

最终选定结果由 `q3_finalize_joint_results(true)` 核对原空间网格下的严格求解记录并导出表4。该选项仅复用输入、模型代码和求解选项均未变化的已完成复核。

六次共同停热检查现已全部完成，均为物理失败，终止原因均为单片电压下降到0.30 V。两项总能量预算分别为3777.902110 J、3768.402110 J。没有把失败轨迹的较低能耗加入可行结果排名。

## 端部热状态与当前答案

在已复核协同方案的启动状态，五片平均温度约为[0.0100,14.4777,19.2411,14.4667,0.0100] ℃，两块端板仍约为[−18.8581,−18.8739] ℃。利用基础模型原始微分方程、保持同一状态和电流，仅令辅助热源为零，得到两端单电池瞬时温度变化率约[−1.5187,−1.5066] K/s；向端板传热约[52.0295,52.0729] W。

这表明当前启动边界受到两端片温度和冷端板吸热影响。中间片虽然温度更高，但也通过片间传热帮助端片升温，因此降低中间功率并不必然减少总辅助能耗。上述导数只是当前状态的局部诊断，不能证明所有功率分配下提前撤热都失败，更不能证明全局最优。完整状态和导数见 `q3_heater_off_diagnostic.mat`。

本轮32个变异候选评价及6个撤热候选均未改善原最低能耗。最终输入和模型没有变化，因此复用了三项已完成的严格复核：纯预热、选定协同分配和满功率协同基准。当前结果仍为：

|策略|功率密度 W/cm²|总辅助能耗 J|启动时间 s|
|---|---|---:|---:|
|纯预热|[1,1,1,1,1]|4189.537083|33.516297|
|恒功率协同|[1,1,1,1,0.995588043]|3778.402110|30.253913|

协同方案相对同精度全满功率方案仅节省约2.059 J；相对纯预热节省约9.81%。这是有限搜索得到的已验证最佳可行记录，仍无全局最优性证明。题目所需完整八列表见 `表4_辅助冷启动优化结果.docx` 和对应PDF/CSV。

后续热模型审查补充：上述约2.059 J差值仅占总能耗约0.054%，尚未经过空间网格收敛验证，不能认定为具有物理意义的节能优势。瞬时热平衡核对通过不代表离散误差足够小；模型范围及证据限制详见 `thermal_model_scope_audit.md`。
