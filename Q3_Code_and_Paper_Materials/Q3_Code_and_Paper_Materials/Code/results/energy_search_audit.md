## 已找到的搜索遗漏

此前 `q3_refine_min_energy` 对协同方式把加热时长设成观察时长，
并用 `E_best/(25*sum(q))+2` 限制观察终点。这只能筛选连续加热的
方案，会漏掉提前关热后依靠反应产热完成启动的方案。
此前提前关热样本在65秒尚未成功，但最低电压仍为0.437 V，
不能由此认定其在题定约束下必定失败。

新接口 `q3_evaluate_energy6` 独立接收五片功率与关热时刻。对于
题定电流斜坡，60秒累积电荷为9 C/cm²；此后每秒增加0.3 C/cm²。
20 C/cm²上限对应96.6667秒，所以协同方式一直观察到成功、物理失败
或电荷上限。数值求解失败单列为未知，并收紧数值容差复算。

## 基础模型对分配的影响

沿用队友模型的独立端板节点、共享双极板热容、水冰电热耦合及
电热丝等效体积热源，不改变题定初温、电流、功率上限。
相邻单电池间导热约2.221 W/K，端片至端板约2.758 W/K。
中间片既自身升温，也向两端供热；因此中间片温度较高不能单独作为
降低其功率必然节能的依据。

辅助能耗为 `E=25*sum(q)*min(th,ts)`。功率、加热时长和成功时间
需要一起评价。端片偏重、中间偏重、均匀降功率、不对称分配都应进入
候选集；不预设最优解一定均匀或一定不均匀。

## 数值修复与口径

求解器在关热时刻按完整状态分段积分。新增开关回归测试、原加热
能量守恒测试和原优化契约测试均通过。这个改动不改变物理方程。
纯预热仍以五片均超过0 ℃作为启动时刻，不增加后续加载时间。
能耗为主目标；能耗在数值精度内相当时优先启动更快的方案。题目没有
另外给出人为启动时限，不通过擅设时间上限改变优化问题。
