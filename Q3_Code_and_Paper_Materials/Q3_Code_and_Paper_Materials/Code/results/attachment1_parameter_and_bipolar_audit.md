## 双极板模型的具体做法

建议先保留现有MEA水热电状态，给实际物理双极板增加独立温度节点T_b，而非直接增加三维流道细节。每块板满足：

    C_b*dT_b/dt = P_b + sum_j G_bj*(T_j-T_b)
    C_b = rho_b*c_b*A*delta_b
    G_bj = A / sum(路径上各段厚度/对应导热系数)

相邻节点位于控制体中心时，路径长度使用两侧各自半个控制体厚度。基准模型按题目忽略热接触电阻。MEA边界接收等大反向热通量，端板仍保留独立蓄热和外部对流。

按面积25 cm²、厚2 mm及附件物性计算，单块这样的板热容为7.5834 J/K。五片串联时需要先明确阴阳极半板如何组成内部双极板，以及五组电热丝分别布置在哪里。采用“6块板”的热容假设与“每片阳/阴极各一块2 mm半板”的计数口径不能混用。题目图2为结构示意，没有逐块标注2 mm定义和五组电热丝位置，需在论文中声明采用的几何解释。

用映射H_bk将第k组加热功率分给实际板节点：

    P_b = 25*sum_k H_bk*q_k [W]
    H_bk >= 0, sum_b H_bk = 1

这样每组输入仍是25*q_k W，全堆始终只有五组独立控制功率。加热位置或两侧分配比例未给定时须列为建模假设及敏感性因素。

必须同时移除原MEA等效热容中已经折算的BP热容，将辅助热源从MEA移至板节点；原来跨MEA的等效片间导热通道应由新节点连接替代。否则会重复计算热容、热源或片间热流。对于MEA内部仍保留原气体、水冰和电化学方程。

增加BP节点不自动保证改变最优功率分配。仍应先核对总热容、每条界面通量相消、全堆能量守恒，以及对基础实验的复现，再重新优化。

## 文献补充范围

题给厚度、密度、比热、导热等无需从其他材料的论文替换。需查证的是未给出的构成关系、相变速率定义、热源分配假设及适用性。题目明确忽略的热接触电阻不应因文献存在就加入基准模型。

- Lin S., Su J., Shi L. *Research on PTC Auxiliary Heating Starting Strategy Based on One-dimensional Multiphase Cold Start Stack Model*. Electrochemistry 93(1), 017001 (2025). https://doi.org/10.5796/electrochemistry.24-00112 。可参考一维多相冷启动、板材热质量及辅助加热的建模组织。该文使用冷却回路PTC加热，和本题板内电热丝的加热路径不同，其功率和控制条件不能直接照搬。
- Wei L. et al. *Effects of Endplate Assembly on Cold Start Performance of Proton Exchange Membrane Fuel Cell Stacks*. Energy Technology 9, 2100092 (2021). https://doi.org/10.1002/ente.202100092 。可支持端板组件热惯性影响端片温度与冰分布的建模依据。

优先顺序：先确认附件与当前闭合关系、板厚/计数及热量记账，再决定是否显式离散BP，最后做有限网格检查与功率优化。原表4仅对原模型及其假设有效，不能当作改进模型的结果。
