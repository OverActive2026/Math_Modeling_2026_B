# Code_ICE_F —— 固定 `gammaIce=3.5`、`kFreeze=0.4` 后的重新联合标定

本目录从 `Code_ICE_E` 完整复制而来，**E 版及其之前的目录均未修改**。
E 版的全部代码修正（`[E-1]`~`[E-6]`，含 −25 degC 的数值鲁棒性修复）在 F 版中
原样保留；**本版只改动标定参数，未改动任何物理方程**。

用户要求原文：*"如果固定 Gamma_ice 是 3.5，K_freeze 是 0.4，看看还能不能
拟合的更好些。"*

结论：**能，但提升幅度有限（合并 RMSE 改善 5.0%）**，原因是模型的温度敏感度
与实测不一致这一结构性矛盾无法通过调参消除（见 §4）。

---

## 1. 与 E 版的差异

| 项 | Code_ICE_E | **Code_ICE_F** |
|---|---|---|
| `gammaIce` | 3.5（固定） | 3.5（固定，同） |
| `kFreeze` | **1**（可标定量） | **0.4（固定，不再标定）** |
| `j0Ref` | 0.30 A/m² | **0.28 A/m²** |
| `mHyd` | 1.55 | **1.70** |
| `clResistanceScale` | 0.64 | **0.66** |
| `tauHyd` | 40 s | 40 s（同） |
| `lamHydRef` | 1.0（固定） | 1.0（固定，同） |
| `directFreezeFraction` | 0.15 | 0.15（同） |
| `freezeNucleationLambdaFraction` | 0.25 | 0.25（同） |
| 水合/欧姆标定量个数 | 4 | **3** |

固定 `kFreeze` 之后，冰的**总量**（由 `kFreeze` 与 `directFreezeFraction`
决定）和冰的**面积惩罚**（由附件1 给定的 `gammaIce=3.5` 决定）都不再参与
拟合，模型只能通过水合/欧姆参数去匹配电压曲线。**因此 F 版的标定结果比
E 版更难"作弊"，可信度更高**——这是本次固定这两个量最大的意义。

## 4. 为什么只有 5% 的提升：结构性上限

模型的温度敏感度高于实测，这是无法通过调参消除的矛盾：

- 两个工况的实测电压曲线**几乎重合**（t=12 s：0.495/0.493 V；
  t=24 s：0.637/0.629 V；t=32 s：0.648/0.634 V），仅差 2~14 mV；
- 题目式(40) 给定 `Ea=67000 J/mol`，在 253.15→248.15 K 之间使 `j0`
  变化 **1.905 倍**，对应活化损失差 `(RT/αF)·ln(1.905) ≈ 29 mV`
  （`Erev` 的熵项反向补偿约 4 mV，净约 25 mV）。

而模型中**所有**温度相关项都把 −25 degC 的电压往下压：
活化损失（+25 mV）、CL 质子电阻（κ 随 T 降低）、低温最大非冻结含水量
`lambdaSat` 随 T 降低（−25 degC 时 6.54 vs −20 degC 时 7.31，水合更差）、
以及低温下更多的冰。没有任何一项起反方向作用。

因此 −20 degC 与 −25 degC 的残差必然"此消彼长"：E 版把 −20 degC 拟合到
0.01432 时 −25 degC 是 0.01480；D 版把 −25 degC 压到 0.00958 时 −20 degC
被推到 0.02514。**F 版能做到 0.01329/0.01437 已经是该约束下接近最优的
平衡点。** 若要进一步改善，需要引入一个"低温使损失减小"的机制
（例如 O₂ 在离聚物/水中的亨利常数随温度下降而升高），或质疑实测曲线的
一致性。**本版没有通过调参掩盖这一矛盾。**

## 5. 标定过程与参数敏感性（`../tmp/F_opt1..F_opt4.m`、`F_select.m`）

标定目标：两工况合并 RMSE `sqrt((RMSE20² + RMSE25²)/2)`。

| 阶段 | 扫描范围 | 结果 |
|---|---|---|
| `F_opt1` | `j0Ref×mHyd×clResistanceScale`（cs≤0.66） | 最优 0.01397 @ 0.30/1.65/0.66 |
| `F_opt2` | 把 `clResistanceScale` 扩到 1.00 | **cs>0.70 后急剧恶化**（cs=0.80 → 0.022，cs=1.00 → 0.051），最优仍在 0.01393 |
| `F_opt3` | 细化 `j0Ref×mHyd×cs×df` | 0.01379 @ 0.28/1.80/0.68 |
| `F_opt4` | 细化 `nf×tauHyd×df×kFreezeDirect` | 平台期 0.01373~0.01379，差异已在第 4 位小数（噪声级），**停止调参** |
| `F_select` | 在 Pareto 前沿上同时看 RMSE 与形状指标 | 见下 |

**关键敏感性发现**：

1. **`clResistanceScale` 不能取 1.0。** 从物理上讲 cs=1 才是"按附件1 的 CL
   离聚物体积分数 0.3 与 Bruggeman 修正完整计入"的完整值，但实测极化曲线
   是"凹"的（最大微分电阻出现在最低电流段），而串联电阻给出的 `j·R` 随电流
   线性增长会让曲线更"凸"，方向相反。因此这个唯象缩放必须保留在 0.64~0.70。
2. **`tauHyd` 强烈地在这两个温度之间此消彼长**：tau=35 → (0.0213, 0.0086)，
   tau=40 → (0.0133, 0.0144)，tau=45 → (0.0084, 0.0217)。tau=40 正好是平衡点。
3. **`mHyd` 越大，拟合越好但中段回升越"过冲"**。这是 F 版相对 E 版唯一的
   代价，见下面的 Pareto 表。

### Pareto 前沿（全部固定 `gammaIce=3.5`、`kFreeze=0.4`）

| 参数 (j0/mHyd/cs) | 合并 RMSE | 最大误差 −20/−25 | 压降达成率 | 回升达成率 |
|---|---|---|---|---|
| 0.30/1.55/0.64（E 版口径） | 0.01441 | 5.11% / 3.92% | 100.7 / 100.6% | 100.3 / 103.5% |
| 0.28/1.60/0.64 | 0.01423 | 4.74% / 3.92% | 100.4 / 100.3% | 101.1 / 104.3% |
| 0.28/1.65/0.64 | 0.01401 | 4.98% / 3.47% | 100.1 / 99.9% | 101.9 / 105.0% |
| **0.28/1.70/0.66（F 版采用）** | **0.01384** | **4.21% / 3.50%** | 101.4 / 101.4% | 104.6 / 107.7% |
| 0.28/1.75/0.66 | 0.01383 | 4.45% / 3.15% | 101.1 / 101.0% | 105.4 / 108.4% |
| 0.28/1.80/0.68 | 0.01379 | 3.68% / 3.74% | 102.4 / 102.4% | 108.1 / 111.1% |

**选择依据**：在"压降/回升幅度偏差均不超过 8%"的约束下取合并 RMSE 最小者，
得到 `0.28/1.70/0.66`。若更看重形状指标的精确匹配，可用
`0.28/1.65/0.64`（压降达成率 100.1%/99.9%，几乎完全命中，合并 RMSE 0.01401，
仅比 F 版差 1.2%）。

## 7. 使用方法

```matlab
cd Code_ICE_F
run_ice_model                    % 主计算，输出汇总表（RMSE / 压降回升达成率 / 冰量）
run_ice_model_voltage_losses     % 电压损失分解 + 产冰过程绘图
```

两个脚本均已验证可直接运行（−20/−25 degC 两工况，结果与本文档一致）。
