\subsection{问题背景}
氢燃料电池（质子交换膜燃料电池，PEMFC）具有能量转化效率高、响应速度快、运行噪声低和排放清洁等优点，在新能源汽车、无人装备、船舶动力、航天动力及寒区供能系统中具有广阔的应用前景~\cite{huang2021lowtemp}。然而，当环境温度低于冰点时，电池内部的残余水和电化学反应生成水容易发生冻结：生成的冰会占据催化层（CL）和气体扩散层（GDL）中的有效孔隙，削弱氧气向反应位点的传输能力，造成电压快速衰减，严重时直接导致启动失败~\cite{luo2018coldstart}。低温冷启动能力因此成为制约氢燃料电池寒区应用与工程化发展的关键因素之一。

从物理过程看，低温冷启动涉及电化学反应、热量传递、气体扩散、水迁移以及水/冰相变等多个强耦合过程~\cite{jiao2009multiphase}，其核心是\textbf{反应产热与环境散热、反应产水与冻结之间的动态竞争}：若电化学反应产热能使电池温度在孔隙被冰完全堵塞之前升至冰点以上，则启动成功；反之，冰在阴极多孔介质中持续累积，气体传输通道逐渐缩小，氧气供应能力下降，电压随之衰减直至反应无法维持。已有研究表明，冷启动失败模式主要归结为阳极侧膜脱水与阴极侧孔隙冰堵两类机制~\cite{yao2020failure}。

在电堆尺度（多片单电池串联），问题进一步复杂化。各片单电池因散热条件、气体分配和初始温度不同而表现出明显的非均匀性：靠近电堆端部的单电池受端板热容与对流换热影响，散热更快、温升更慢，更容易出现局部结冰和低电压现象，往往成为决定整堆启动成败的薄弱环节~\cite{ma2026endplate}。在启动策略层面，电流加载方式直接影响产热与产水的时序竞争——电流过小则产热不足、冰持续积累，电流过大则加速产水与冰堵，引起单片电压快速下降~\cite{jiang2010ramping}；而仅依靠反应产热的自冷启动在极低温（如 $-30~^{\circ}\mathrm{C}$ 及以下）下往往难以成功，引入辅助加热虽能改善启动性能，却会带来额外能耗，需要在启动速度、能耗与单片一致性之间进行权衡~\cite{amamou2016review,song2025adaptive}。

因此，建立能够反映水热状态与电化学性能的氢燃料电池瞬态冷启动模型，并在此基础上对电流加载策略与辅助加热控制进行优化，对提升氢燃料电池的寒区环境适应性具有重要的理论意义与工程价值。

\subsection{问题描述}
围绕氢燃料电池低温冷启动的建模与控制策略优化，本文需要依次解决以下四个问题。

\begin{enumerate}
  \item \textbf{问题一：一维单电池瞬态自冷启动模型建立及验证。}在题目给出的常温一维参考模型基础上引入冰的影响，将总水量分为水蒸气、液态水和固态冰三种形态，建立含液态水/冰相变控制方程的瞬态自冷启动模型，并根据冰累积量修正有效孔隙率、有效扩散系数及催化层有效反应面积。利用附件1的参数进行数值计算，获得单电池平均温度、冰体积分数与电压随时间的变化规律；利用附件2中 $-20~^{\circ}\mathrm{C}$ 与 $-25~^{\circ}\mathrm{C}$ 的冷启动实验数据进行参数校准与模型验证，分析相对误差与模型预测能力。
  \item \textbf{问题二：给定电荷量约束下的电堆自冷启动策略建模与优化。}针对 5 片单电池串联的电堆，计入相邻单电池间的导热与端部单电池同环境的对流换热，建立电堆瞬态冷启动模型。在单位面积累积电荷量上限 $q_{\max}=20~\mathrm{C\cdot cm^{-2}}$ 和最大电流密度 $j_{\max}=0.5~\mathrm{A\cdot cm^{-2}}$ 的约束下：其一，在初始温度 $-10~^{\circ}\mathrm{C}$ 条件下，分别设计恒流、线性升载和分段阶梯形式的加载曲线 $j(t)$，以缩短达到启动成功条件的时刻 $t_s$ 为优化目标并比较三种策略；其二，确定电堆能够实现自冷启动的最低初始温度 $T_0$，并分析低于 $T_0$ 时导致启动失败的关键单电池及其原因。
  \item \textbf{问题三：电堆辅助冷启动策略建模与优化。}在各片单电池双极板内布置功率可独立调节的电热丝，在自冷启动模型中引入辅助加热项，建立 $-30~^{\circ}\mathrm{C}$ 环境下的电堆辅助冷启动模型。针对纯预加热启动与恒定功率协同启动两种方式，以各片加热功率密度 $q_k$ 与加热持续时间为决策变量，在满足冷启动成功条件的约束下最小化辅助加热总能耗，给出总启动时间与各片能耗分配，并比较两种策略在能耗、启动速度和端部单电池冰堵抑制效果上的差异。
  \item \textbf{问题四：电堆动态辅助加热控制策略优化。}在问题三的基础上允许各片电热丝功率随时间独立调节，以实时测得的单片温度 $T_k(t)$ 与电压 $V_k(t)$ 为反馈信号，结合温升速率与电压下降速率设计动态功率控制策略 $q_k(t)$，并满足功率密度限幅、冰体积分数阈值、电压安全下限等约束。针对完全冷却与两种未完全冷却（$-30~^{\circ}\mathrm{C}$ 环境中分别冷却 20 min、40 min）的初始温度场工况，以辅助加热总能耗最小为主要目标，兼顾启动时间、电堆最大温差、最低单片电压与最大冰体积分数，确定动态控制策略并与恒功率策略比较；进一步研究预冷时间在 10--100 min 内变化时不同预冷程度对恒功率策略冷启动结果的影响。
\end{enumerate}

\subsection{问题一的模型建立}

\subsubsection{变量定义与数据处理}
根据题意确定决策变量 $\bm{x}=(x_1,x_2,\ldots,x_n)^{\mathsf T}$，并对输入数据进行统一处理。数据预处理的规则应在建模前确定，以保证不同方法的比较使用相同的数据基础。

\subsubsection{目标函数与约束条件}
为演示公式排版，考虑带总量约束的加权平方偏差模型：
\begin{equation}
  \begin{aligned}
    \min_{\bm{x}}\quad
      &F(\bm{x})=\sum_{i=1}^{n}w_i(x_i-a_i)^2,\\
    \text{s.t.}\quad
      &\sum_{i=1}^{n}x_i\le b,\\
      &x_i\ge 0,\qquad i=1,2,\ldots,n.
  \end{aligned}
  \label{eq:model}
\end{equation}
\Cref{eq:model} 中，$w_i$ 用于描述不同偏差项的相对重要性。正式建模时应解释目标函数的实际意义，以及各项约束与原问题之间的对应关系。

\subsubsection{模型性质}
当各权重均为正时，目标函数的 Hessian 矩阵为
\begin{equation}
  \nabla^2F(\bm{x})
  =2\operatorname{diag}(w_1,w_2,\ldots,w_n).
  \label{eq:hessian}
\end{equation}
由\Cref{eq:hessian} 可知目标函数严格凸。在约束集合非空的条件下，结合可行域的结构，可以进一步分析最优解的存在性与唯一性。

\section{模型检验与灵敏度分析}

\subsection{模型检验}
将模型输出与已知结果、保留数据或基准方法进行比较，检查结果是否满足实际约束。若采用误差指标，应写清定义、计算范围和比较方式，避免仅凭图形相似就认定模型有效。

以观测值 $y_i$ 和预测值 $\hat y_i$ 为例，均方根误差可写为
\begin{equation}
  \operatorname{RMSE}
  =\sqrt{\frac{1}{m}\sum_{i=1}^{m}(y_i-\hat y_i)^2}.
\end{equation}
误差分析应结合问题的量纲与实际需求解释，必要时分别讨论总体误差和局部误差。

\subsection{灵敏度分析}

\subsection{程序示例}
下列 Python 代码仅用于演示代码排版与目标函数计算，不是完整求解器。实际提交时应替换为能够复现论文结果的程序。

def objective(x, targets, weights):
    if not (len(x) == len(targets) == len(weights)):
        raise ValueError("Input lengths must match.")
    if any(weight <= 0 for weight in weights):
        raise ValueError("Weights must be positive.")
    return sum(
        weight * (value - target) ** 2
        for value, target, weight in zip(x, targets, weights)
    )


value = objective([1.0, 2.0], [1.5, 2.5], [1.0, 2.0])
print(value)
\end{lstlisting}
