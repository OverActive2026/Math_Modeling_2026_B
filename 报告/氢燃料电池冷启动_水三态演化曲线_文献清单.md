# 冷启动过程中"水–冰–气三态变化曲线"的文献清单

> 整理日期：2026-09-24
> 说明：本清单回答"有没有文献给出冷启动中 mv（水蒸气）/ ml（液态水）/ mi（冰）随时间的变化曲线"。
> 结论是——**三态同框的曲线在文献中很少见**，常见做法是拆开画。下面按"建模类 / 实验类 / 成像类"给出真正有曲线的文献。

## 0. 先说清楚文献实际画了什么

| 文献类型 | 通常给出的曲线 | 对应赛题变量 |
|---|---|---|
| 多相建模 | CL/GDL 内**冰体积分数（ice fraction / ice saturation）**随时间的空间分布；**膜含水量 λ(t)** | mi、膜内水 |
| 实验 | **累积产水量 mg/cm²**（总水量，即 mv+ml+mi 的积分）；HFR（膜含水量代理） | 总水量、膜内水 |
| 成像（光学/中子/X 射线） | 冰与液态水的**空间分布随时间**的序列图 | mi、ml |

水蒸气相一般不单独成线：零下饱和蒸气压极低（−20 ℃ 仅 103 Pa），排气携带量不足产水的 1%，量级上可忽略（见水量平衡核算）。

## 4. 对赛题建模的两点提醒（重要）

1. **ml 与 mi 的分界不是严格的 0 ℃。** 实验（Ge 2006、Ishikawa）证实零下存在**过冷液态水**。赛题模型按 T < 273.15 K 直接判冰是合理简化，但在模型假设里应显式写明"忽略过冷态"，并在误差分析时说明这一简化对结冰时刻预测的影响（会**偏早**预报结冰）。
2. **可用来校准的"曲线"其实是累积产水量 mg/cm²**（E1/E2）。这是实验上唯一能干净测到的总量，建议把它作为问题1 模型验证的第三个观测量（除电压、温度外）——比"冰体积分数"更可验证，因为后者实验测不到。
