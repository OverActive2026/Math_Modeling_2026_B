# 问题4第（1）小问：测试网格提交版

本目录只提交计算代码，不提交大型仿真结果。统一使用五片网格
`[2 3 4 4 2]`、`kFreeze=0.4 s^-1`、`gammaIce=3.5`、
`kMelt=1 s^-1`。它用于快速复现与调参，**不是正式空间网格验证**。

在 MATLAB 中进入本目录，依次运行：

```matlab
run_q4_online_rule_case1             % 工况1：在线动态加热
run_q4_online_precooling_cases23     % 工况2/3：预冷初值、在线控制及全功率参考
run_q4_case1_full_power_reference    % 工况1：全功率可行性参考（可选）
```

`run_q4_precooling` 可单独输出20/40 min预冷温度场，本提交版也设为测试网格。
`run_q4_tune_online_policy_case1` 与 `run_q4_refine_online_policy_case1`
保留在线规则的参数搜索过程，运行时间较长；直接复算不必先运行它们。
所有生成的 MAT 与 PNG 位于 `results_control` 或 `results_precooling`，
被 `.gitignore` 排除。

当前已在原工作目录的测试网格上复算：工况1在线启动约 `30.483 s`、
辅助能耗约 `3740.493 J`；工况2为 `5.625 s / 703.181 J`；工况3为
`19.227 s / 2361.339 J`。这不是正式网格结果，也不能证明全局最优。

重要限制：脚本里的 `1 W/cm²` 全功率轨迹只是可行性参考，**不是**题目要求
与之比较的“问题3恒功率协同启动最优策略”。问题3的候选功率分配尚未针对
三个预冷初值重新优化；表4中的恒功率最优列不能用全功率结果冒充。
本次因时间限制没有进行正式网格计算，也没有重跑这些长耗时仿真。
