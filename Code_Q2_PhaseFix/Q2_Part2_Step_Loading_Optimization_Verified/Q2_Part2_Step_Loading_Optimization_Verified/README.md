# 问题2阶梯加载：审计修正版

这是独立的六/七档阶梯加载代码包，不是线性加载，也不是最低启动温度 T0 的完整求解。原文件夹保持不变。建议 MATLAB R2024b；寻优需要 Statistics and Machine Learning Toolbox。

## 运行

将 MATLAB 当前文件夹切换到本文件夹。为避免同名函数混用，先停止其他仿真，再运行 `clear functions`。

```matlab
test_q2_verified_logic           % 合成回归测试，不代表物理启动性能
r7 = verify_q2_reference(7);     % 独立复算原七档 c05，-10 / -11.2°C
r6 = verify_q2_reference(6);     % 独立复算精确六档参考，-10 / -11°C
report = run_q2_verified_optimization(3); % 七档13变量，在-11.2硬约束下继续寻优
result = verify_q2_optimized;    % 不读缓存、不使用incumbent截断，独立复算最优点
```

第一次寻优运行除指定的进一步候选次数外，还评估两个初始种子。后续运行复用已经确定的物理结果；未知/截尾结果不作为物理约束标签复用。可选六档入口：

```matlab
report6 = run_q2_verified_optimization(3,6,-11);
result6 = verify_q2_optimized(6,-11);
```

## 目标与固定条件

最小化 -10°C 仿真启动时间，同一开环曲线在指定冷端也必须满足真实模型硬约束。七档默认冷端-11.2°C；六档默认-11°C。冷端启动时间不进入优化目标。

模型原样复制，gammaIce=3.5、kFreeze=0.4 s^-1、快速网格[2 3 4 4 2]；jMax=0.5 A/cm²、qMax=20 C/cm²、全过程最低单电池电压0.30 V，其余约束沿用原模型；无辅助热源。搜索及独立复算均使用 RelTol=5e-5、AbsTol=5e-9。模型已有微小浮点判定容差保留不变。

每个温度默认600 s计算预算；预算超时只表示“未知/截尾”，不证明物理不可行。暖端incumbent+0.5 s截断只节省评估成本；冷端仍使用独立600 s预算。失败/未知的startup_time均为NaN，数值失败与时间截尾均排除约束和时间GP训练。

六档11变量、七档13变量均自由。恢复原六档间隔搜索范围[0.5,30]、[0.5,60]、[0.5,90]、[0.5,120]、[0.5,30]秒；七档增加[0.5,30]秒第六间隔。允许非单调电流以及晚于暖端启动的切换。这些是明确的计算搜索边界，不是题目物理约束，也不保证涵盖所有可能曲线。

算法保留 FuRBO 启发的可行性驱动信赖域与稳定解析 LogEI，含局部风险/缓存等工程机制，不是 FuRBO 严格复现。小样本各向同性核阈值是启发式，不是可辨识性定理。

参考：[Ascia等，FuRBO](https://arxiv.org/abs/2506.14619)；[Ament等，LogEI](https://arxiv.org/abs/2310.20708)。

## 审计问题的修复

- 聚合成功须所有目标温度status均为1，冷端失败或未知不能输出joint success。
- 状态1可行、-1物理失败、-2数值未知、-3预算/目标截尾、0未评估。
- 冷端温度真正加入每个候选的搜索约束，不再只事后复核。
- 不导入旧91点缓存；新缓存包含完整温度、选项与源代码内容，设置不一致时拒绝复用。
- custom evaluator覆盖与完整基准选项比较，只允许计算时间覆盖，不能默默使用默认物理参数。
- 新六档参考MAT只保存精确曲线，不包含旧成功标签或污染缓存。
- 每条真实新评估保存独立wallSeconds；报告启动时间来自successTimeS。缓存命中耗时不是原仿真耗时，累计新包评估成本另列。
