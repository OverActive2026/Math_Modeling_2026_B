# Q2（2）：线性加载的已验证低温启动结果

本文件夹是独立的 MATLAB 资料包，用于第二题第（2）小问的论文撰写与后续复核。这里固定**同一条线性升流、达到平台后恒流**的曲线 `j(t)=min(j0+r·t,jp)`，同时改变五片电堆的初始温度和环境温度；它不是从 `t=0` 起全程恒流的模型。文件夹名称沿用其他 `Minimum_Startup_Temperature` 资料包的格式，但目前只能报告**已测试温度中的最低成功点**，不能声称已求得精确或全局最低启动温度。

## 曲线来源与 5% 时间限制

原来仅按 `−10 ℃` 最短启动时间选出的线性曲线为 **40.726546388 s**。本资料包采用“`−10 ℃` 启动时间最多增加 5%，再尽可能降低可启动初温”的选择规则，因此时间上限为 **42.762873707 s**。选出的固定曲线来自真实五片模型的 FuRBO 启发式信赖域和 LogEI 搜索，精确参数保存在 `optimization_results/q2_linear_cap5_verified_report.mat`：

```text
j0 = 0.144980839828 A/cm²
r  = 0.006798554947 A/(cm²·s)
jp = 0.478303370156 A/cm²
j(t) = min(j0 + r·t, jp)
```

这条曲线在 `−10 ℃` 的复算启动时间为 **41.991669327 s**，比原最快值慢 **1.265122939 s（3.1064%）**，满足 5% 限制。电流始终不超过题目给出的 `0.5 A/cm²` 上限。

模型使用 `[2 3 4 4 2]` 五片快速网格、`gammaIce=3.5`、`kFreeze=0.4 s^-1`、`RelTol=5e-5`、`AbsTol=5e-9`。成功判据是五片平均温度均达到 `0 ℃`，并且全过程满足最小单片电压 `0.30 V`、累计电荷 `20 C/cm²`、电流 `0.5 A/cm²`、局部冰体积分数 `0.99` 和模型孔隙占有率 `0.98` 的限制。结果为模型仿真，不是实验测量或完整网格验证。

## 独立复算与文件分工

把整个文件夹复制到任意位置，在 MATLAB 中进入该目录并执行：

```matlab
summary = replay_q2_linear_temperature_checks([-10 -11 -12]);
```

该命令会**重新运行**五片模型，并在命令窗口约每 5 秒仿真时间显示进度；随后将每个温度的完整轨迹、结果表和 CSV 写入 `optimization_results/replayed_trajectories`。如果只想阅读已有结果，无需运行它。`replay_q2_linear_temperature_checks.m` 是复算入口；`pemfc_*.m`、`*_state_ice.m`、`q2_current_strategy.m` 为物理模型；`q2_decode_strategy.m`、`q2_evaluate_real.m`、`q2_optimization_options.m` 为加载曲线与模型接口。优化报告保存精确曲线和 −10、−10.1 ℃ 的独立验证结果，`q2_linear_minus10_reference.mat` 保存原最快曲线的对照结果。本包不包含新的寻优入口，后续继续寻优应回到 `Q2_Optimized_Linear_Loading`。

## 论文表述建议

可写为：“在 −10 ℃ 启动时间不超过原线性加载最优值 105% 的约束下，采用固定线性升流—平台电流策略；所得曲线在 −10 ℃ 的启动时间为 41.99 s（较原最优增加 3.11%），在已测试的 −11 ℃ 可于 44.67 s 完成无辅助热源自冷启动。该固定曲线在 −12 ℃ 因单片电压先达到 0.30 V 下限而失败。若该曲线的启动可行性在此温度段随初温单调，临界温度位于已测的 −11 ℃ 成功点与 −12 ℃ 失败点之间；精确边界及关键单片需进一步轨迹分析。”
