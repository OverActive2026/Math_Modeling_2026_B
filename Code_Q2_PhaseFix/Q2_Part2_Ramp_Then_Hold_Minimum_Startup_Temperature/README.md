# 第二题（2）：固定优化后升流—恒流曲线的最低自冷启动初温

本文件夹可独立复制给队友，用于复核问题2第（2）问的一组**固定加载曲线**的最低可启动初温，并提供模型、逐温度轨迹和论文表述素材。文件夹名称中的“恒流升载”指 **先升流、后恒流**；这条曲线不是从 `t=0` 就保持同一电流密度的真正全程恒流。

## 加载曲线与模型

采用问题2第（1）问在 `−10 ℃` 下找到并独立复跑的优化后曲线：

```text
j(t) = 0.02 + (0.2668808447608863 − 0.02)t/2，0 ≤ t < 2 s
j(t) = 0.2668808447608863 A/cm²，t ≥ 2 s
```

五片单电池串联，电流密度相同；每片使用一维气体传输、水/冰相变、温度和电压耦合模型，电池间导热、端板热容及对流散热由 `pemfc_stack5_simulate.m` 计算。每次温度试算把电堆**初温和环境温度同时**设为待测值，保持曲线、物理参数、网格与数值设置不变。`gammaIce=3.5`、`kFreeze=0.3`，网格 `[2 3 4 4 2]`，原单次 `ode15s` 积分。成功需五片平均温度均达到 `0 ℃`，且全过程符合单片电压不低于 `0.30 V`、局部冰体积分数小于 `0.99`、累计电荷不超过 `20 C/cm²`、电流不超过 `0.5 A/cm²` 等约束；代码另检查孔隙占用率。数值来源为本文件夹随附的已验证优化报告和温度轨迹。

最冷的**已验证成功点为 `−11.0703125 ℃`**，相邻失败点是 `−11.078125 ℃`。若临界点附近的可行性随温度单调，阈值位于两者之间，搜索区间宽度 `0.0078125 ℃`。论文中建议写为“**约 −11.07 ℃（该固定曲线、粗网格模型的数值结果）**”，不应把小数位视为实际装置的温度精度。

失败边界由**第 1 片单电池**控制。在 `−11.078125 ℃`，它于 `64.737831 s` 首先降至 `0.30 V`；当时第 1 片平均温度约 `−0.599 ℃`、最大局部冰体积分数约 `0.4002`，第 5 片约 `−0.247 ℃`，中间三片均已超过 `2 ℃`。电荷尚余约 `2.97 C/cm²`，局部冰体积分数也未达到 `0.99`；因此直接触发的是端部第 1 片的低电压，而其低温及局部结冰是重要的伴随因素。在相邻成功点，最低电压仍有约 `0.001405 V` 余量，随后恢复并在 `73.916039 s` 完成升温。

## 论文可改写的模型说明

可将第（1）问在 `−10 ℃` 下获得的优化后加载曲线固定，构造初温为外层变量的可行性判定：对每个候选 `T₀`，令初始堆温与环境温度均为 `T₀`，积分五片耦合瞬态模型，记录首次满足五片平均温度均不低于 `0 ℃` 的时刻；若在此前任一单片电压、冰或孔隙占用等约束先触发，或累计电荷达到上限，则判为失败。先按 `1 ℃` 向低温扫描，再在成功与失败之间二分。边界两侧轨迹比较表明，端部第 1 片先触及电压下限，是本固定加载曲线在更低初温下失败的直接原因。

这只是**固定 −10 ℃ 优化结果后继续降温**的条件性答案。若题目第（2）问需要“允许在每个初温重新优化三类加载策略的全局最低初温”，还须为每个初温重做内层寻优，并比较恒流、线性升载和阶梯加载；本文件夹的 `−11.07 ℃` 不能直接充当那个全局结果。当前仅在粗网格上验证，尚未做完整网格的离散误差检查。

## 独立复核

把**整个文件夹**复制到任意位置，在 MATLAB 中进入该目录：

```matlab
scan = find_q2_optimized_min_temperature(0.01);
plot_q2_temperature_boundary();
```

第一行读取已保存的 `scan.mat` 并输出边界；如果请求更小的温度间隔，它会继续运行模型，同时在命令窗口打印模拟时间。第二行重建边界对比图和结果 CSV。若要从头搜索，删除本文件夹 `optimization_results/fixed_optimized_temperature/scan.mat` 后再运行第一行；逐温度 `.mat` 轨迹会被同名新结果覆盖。`pemfc_*.m`、`*_state_ice.m` 和 `q2_current_strategy.m` 为必需模型代码，优化报告仅供固定加载曲线和模型参数的来源验证。

**数据位置：** `optimization_results/fixed_optimized_temperature/scan.mat` 为温度边界和全部试算索引；同目录 `T_*.mat` 为各温度的完整五片轨迹；`optimization_results/constant_fixed_reference_kfreeze03/*_report.mat` 为原优化报告。报告内部可能保留生成时的旧绝对路径元数据；本文件夹脚本运行时会重新定位所有所需文件。
