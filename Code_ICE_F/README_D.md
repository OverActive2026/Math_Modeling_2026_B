# Code_ICE_D —— 三阶段同时达标的最终版

本目录在 `Code_ICE_A` 基础上新增 **j0 水合因子 `[D-1][D-2]`**，
最终实现「初始段压降 / 中段回升 / 后段电压」三段同时拟合。

## 一、最终参数

```matlab
Ea   = 67000;      % [J/mol]  题目式(40) 给定值，未改动
alpha= 0.5;        %          题目式(39) 给定值，未改动
j0Ref        = 0.020;   % [A/m^2]  参考交换电流密度（标定）
mHyd         = 1.35;    %          j0 的水合指数（[D-1] 新增，标定）
lamHydRef    = 0.10;    %          fHyd 的参考 λ（[D-2] 新增，取 t=0 实际值）
clResistanceScale = 0.65; %        CL 离聚物质子电阻缩放（标定）
tauHyd       = 40;      % [s]      cCL 水合时间常数（标定）
gammaIce     = 0.1;     %          冰面积修正（本组算例中冰量很小）
```

## 三、机理：为什么三段能同时对上

三次分解（`tmp/phases.m`）表明，实测电压里有一个"扣掉电流影响后
纯时间驱动"的损失，形状是：**早段出现 → 中段消失 → 后段反向**。

它对应**两个作用在不同时间尺度上的机制**：

| 机制 | 数学形式 | 时间行为 | 负责阶段 |
|---|---|---|---|
| **cCL 离聚物质子电阻** | `R_CL ∝ 1/κ(λ)`，欧姆损失 `∝ j` | **电流驱动**，只在电流大时显著 | 前段压降 |
| **j0 水合因子** | `fHyd = (λ/λ_ref)^mHyd` | **与 j 无关**，随水合单调上升 | 中段回升 + 后段 |

**关键就在于这两者解耦**：之前只用 CL 电阻一个旋钮时，调大能补前段
但会压垮后段（我扫过 24 组参数都无法解耦）。加入 `[D-1]` 的水合因子后，
"回升"由与电流无关的水合因子驱动，"压降"由与电流成正比的电阻驱动，
两个自由度分开，三段才能同时命中。

### `[D-1]` 的物理依据（量化）

实验反解出的有效 j0 从 t=0 到 t=36.6 s 上升约 **18.3 倍**
（`tmp/late.m`）。而题目式(40) 只含温度项：

$$j_0(T)=j_{0,\mathrm{ref}}\exp\!\left[-\frac{E_a}{R}\left(\frac1T-\frac1{298.15}\right)\right]$$

`Ea=67000 J/mol` 在 253.15→260.96 K 之间**只能给出 2.59 倍**，缺约 **7 倍**。

物理来源：离聚物吸水后体积膨胀、覆盖更多 Pt 表面、提高质子可达性，
**有效三相界面面积显著增加** → 交换电流密度随 λ 上升。

$$j_0^{eff}=j_0(T)\cdot\underbrace{\left(\frac{\lambda_{CCL}}{\lambda_{ref}}\right)^{m_{Hyd}}}_{\text{新增}}\cdot f_{Area}$$

### `[D-2]` 参考点为什么取 0.1

`fHyd` 必须在 t=0 处等于 1，否则会整体平移电压曲线。
t=0 时 cCL 还未水合，模型给出的 `λ_CCL≈0.1`，
因此取 `lamHydRef = 0.10`。实测：取 1.0 时 t=0 误差 8~11%，
取 0.10 后降到 0.6~2.3%。

## 五、关于"题目强调冰是否误导"

三种"结冰"机理的水量需求（`tmp/timing.m`）：

| 机理 | 需要的水 | 何时可得 |
|---|---|---|
| **表面覆盖**（冰盖住 Pt/离聚物界面） | 6.6e-8 kg/m² | **t≈0 s** |
| 离聚物水合（λ: 1→4.84） | 5.03e-4 kg/m² | t≈12.2 s |
| **孔体积填充**（s_ice→1） | 4.37e-3 kg/m² | **t≈31 s** |

**结论**：结冰机理是题目要求的核心内容，必须建（模型里也确有冰）；
但**电压曲线的前段压降主要由 cCL 离聚物脱水引起的质子电阻上升决定**，
冰的作用在 t>25 s 后才逐渐显现。题目正文用"孔体积分数"（式(9)）描述
冰的影响，而实测数据指向的是**面积覆盖**（附件1 的"阴极冰覆盖活性
面积指数 3.5"恰好是面积口径）。这一点可以在论文的模型讨论中说明。
