# Code_ICE_A —— 标定固化版（Ea 锁题目给定值）

本目录由 `Code_ICE_DSH` 复制并继续修改，用于验证
「**能不能靠 CL 离聚物电阻 + 冰来解释电压曲线**」以及固化可用的标定结果。

## 一、当前默认参数（已写入 `pemfc_calculate_ice.m`）

```matlab
Ea     = 67000;    % [J/mol]  题目式(40) 给定值，未改动
alpha  = 0.5;      %          题目式(39) 给定值，未改动
j0Ref  = 0.1898;   % [A/m^2]  由 -20/-25 两个温度全部实测极化点联合拟合
clResistanceScale = 0;   % CL 离聚物质子电阻缩放：0=关闭，1=完整 [FIX-5]
```

`j0Ref` 的来历：固定 `Ea=67000`、`alpha=0.5`，以
`{j0Ref, R_extra}` 为二维决策变量，用附件2 两个温度的全部 368 个实测点
（`V` 对 `j`）做最小二乘。最优解为

```
j0Ref = 0.1898 A/m2 ,  R_extra = 0.000 ohm cm2 ,  RMSE = 0.0611 V
```

**拟合器把串联电阻主动推到 0**，这是本目录最重要的结论（见第三节）。

## 三、结论：CL 离聚物电阻**不能**用来补这个缺口

理由（详见 `tmp/definitive_fit.m`）：

1. **二维拟合的最优解把 R_extra 推到 0。** 任何正的串联电阻都会让拟合变差。
2. **原因是形状，不是量级。** 实测极化曲线的微分电阻 `dV/dj`：
   - j=0.006→0.025 段：**5.3 Ω·cm²**（最大）
   - j=0.167→0.189 段：**0.23 Ω·cm²**（最小）
   
   即曲线是**凹**的。而串联电阻给出 `j·R`，随电流线性增长，会让曲线更**凸**。
   方向相反，所以拟合器拒绝它。
3. **模型在高电流段的微分电阻是 0.67 Ω·cm²**（活化 0.44 + 膜 0.23），
   而实验只有 0.23。也就是说实验在那一段"几乎只有欧姆"，Tafel 斜率
   贡献小到看不见 —— 这要求一个**在低电流就强、随电流饱和**的额外损失，
   串联电阻做不到。

## 四、剩余缺口的定位

t=10~15 s，j ≈ 0.09~0.16 A/cm²，模型高 0.10~0.12 V。这一段是
**冰正在生成**的区间，但模型里 ice 仍是 0（−20 ℃）或 0.016（−25 ℃）。

冰之所以起不来，根因是参考模型的水账（见 `Code_ICE_DSH/README_DSH.md`）：
cCL 水活度全程只到 0.66~0.95，从未达到 1，液水无法生成。
`tmp/ice_ceiling.m` 显示即使把保水强度压到极限（fRet=0.03），
cCL 冰饱和度上限只有 0.53，而且**单调累积不回落**（末值=最大值），
与实验要求的"先涨后消"形状不符。

**下一步候选**（按性价比）：

1. **CL 内氧传输阻力**（离聚物相 O₂ 渗透）——标准机理，参数少，
   形状恰好是"低电流影响大、高电流饱和"，与残差形状吻合。
2. 把冰的作用从"均匀孔堵"改为"选择性覆盖活性位点"。
3. 接受现状：V_RMSE ≈ 0.05 V、T_RMSE ≈ 0.1 K，把 t=10~15 s 的
   0.11 V 作为模型局限写入论文。
